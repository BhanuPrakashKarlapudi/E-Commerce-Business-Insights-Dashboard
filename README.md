# 📌 Project Overview

The **E-Commerce Business Insights Dashboard** is an interactive Power BI project developed to analyze business performance using sales, customer, and return data.

The dashboard enables stakeholders to monitor key business metrics, identify sales opportunities, understand customer behavior, and analyze return patterns through interactive visualizations and actionable business insights.

---

# 🎯 Business Objectives

- Analyze overall sales performance
- Monitor sales trends over time
- Identify top-performing regions and product categories
- Evaluate customer purchasing behavior
- Analyze return patterns and return reasons
- Generate business insights for decision-making

---

# 📄 Dashboard Pages

## 1️⃣ Executive Overview

### KPIs

- 💰 Total Sales
- 📦 Total Orders
- 🔄 Return Rate
- 📈 Units Sold
- 👥 Customer Count

### Visuals

- Return Rate by Month
- Category-wise Sales

### Key Insights

- Electronics generated the highest sales.
- April recorded the highest return rate.
- December achieved the highest monthly sales.

---

## 2️⃣ Sales Performance Analysis

### Visuals

- Total Sales & Orders by Region
- Total Sales by Payment Method
- Order Trend by Year

### Key Insights

- South generated the highest sales and order volume.
- Credit Card was the most preferred payment method.
- 2024 recorded the highest order volume.

---

## 3️⃣ Customer & Returns Analysis

### Visuals

- Return Rate by Category
- Return Rate by Region
- Return Reason Analysis

### Key Insights

- Fashion recorded the highest return rate.
- East region experienced the highest return rate.
- "Not as Described" was the leading return reason.
